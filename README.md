# 📦 AgilStore - Sistema de Gerenciamento de Inventário

Este é um sistema de controle de estoque desenvolvido em **Node.js** para o desafio técnico da AgilStore. A aplicação permite gerenciar produtos de forma eficiente através do terminal.

## ✨ Funcionalidades
- **Cadastro:** Adicione produtos com ID automático, nome, categoria, quantidade e preço.
- **Listagem:** Visualize todo o inventário em uma tabela organizada.
- **Busca:** Encontre produtos rapidamente por nome ou ID.
- **Atualização:** Edite informações de produtos já cadastrados.
- **Remoção:** Exclua itens do estoque com segurança.
